# Security

Do not open a public issue containing an API key, CSV content, personal data or a complete private request. Rotate an exposed RapidAPI key from the application authorization settings.

For product support, use the RowGuard discussion or support channel on RapidAPI and provide only the `request_id`, HTTP status, aggregate summary and non-sensitive reproduction details. RapidAPI and Cloudflare process transport and usage metadata under their own policies.
